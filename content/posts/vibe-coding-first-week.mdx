이번 주에 처음으로 AI 코딩 도구와 함께 개인 블로그를 처음부터 끝까지 만들어 봤다. 결과물보다 과정에서 배운 것이 많아서 기록해 둔다.

## PRD부터 쓴 이유

코드를 한 줄도 쓰기 전에 무엇을 만들고 무엇을 만들지 않을지를 문서로 먼저 정리했다. 제외 범위를 적어 두니 AI가 제안하는 기능을 거절하기가 훨씬 쉬웠다.

- 목표와 제외 범위를 함께 적는다
- 디자인 원칙(색, 폰트, 폭)을 미리 못 박는다
- 마일스톤을 작게 쪼갠다

## 작게 나눠서 만들기

한 번에 큰 기능을 요청하면 결과를 검토하기 어렵다. 화면 하나, 컴포넌트 하나 단위로 요청하고 매번 빌드가 통과하는지 확인하는 방식이 가장 안정적이었다.

```bash
npm run build
npm run lint
```

## 이번 주에 남은 것

AI는 빠르게 만들어 주지만 무엇이 좋은 결과인지는 내가 정해야 한다. 다음 주에는 글 작성 흐름(MDX)을 붙여 볼 계획이다.
